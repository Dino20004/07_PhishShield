# Security Policy

## Supported Versions

Only the latest active release version receives security updates.

| Version | Supported |
| ------- | --------- |
| 1.0.x   | Yes       |

## Reporting a Vulnerability

As a cybersecurity extension, we take the security of PhishShield AI extremely seriously. If you find a security vulnerability, bypass exploit, or false negative pattern, please do not open a public issue. 

Instead, report it directly to the security maintainers by emailing: **security@phishshield-ai.local** (or opening a private security advisory on GitHub).

Please include the following details in your report:
- A detailed description of the vulnerability.
- Step-by-step instructions or proof-of-concept URLs to reproduce the issue.
- Details of the browser name and version used during the test.

We aim to acknowledge receipt of your report within 48 hours and release an official patch within 14 days of confirming the issue.
